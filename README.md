# Exhibition Wall Planner

Five walls:
- Wall 1 — 22 m × 2.40 m
- Wall 1 — 15.7 m × 2.40 m
- Wall 2 — 15.7 m × 2.40 m
- Wall 2 — 9.4 m × 2.40 m
- Wall 3 — 9.4 m × 2.40 m

Only A0, A1 and A2, each portrait or landscape.

Run:
npm install
npm run dev

The planner autosaves each wall in IndexedDB. Use Backup JSON regularly as an extra backup.
